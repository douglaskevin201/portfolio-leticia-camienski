# Portfólio de Leticia Camienski

Site estático para apresentar projetos de arquitetura, interiores e paisagismo.

Criado por **Kevin Douglas** para apresentar o portfólio de **Leticia Camienski**.

## Executar localmente

Com o Python instalado, abra o terminal nesta pasta e execute:

```powershell
py -m http.server 8000
```

Depois, acesse <http://localhost:8000>.

Também é possível abrir `index.html` diretamente, mas algumas funções do navegador funcionam melhor usando o servidor local.

## Arquivos privados

O currículo e outros documentos pessoais ficam em `docs/`, que é ignorada pelo Git. Arquivos PDF e documentos do Office também são ignorados para evitar publicá-los por engano.
